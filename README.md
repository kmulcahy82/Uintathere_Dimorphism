# Uintathere_Dimorphism
Code used in the project "Linear morphometrics fail to support strong sexual dimorphism in Uintatherium anceps." These analyses test the classical paleontological hypothesis that uintatheres, mammals belonging to the extinct order, Dinocerata, exhibit strong sexual dimorphism. 

All scripts are run in R. Datafiles used can be found on Zenodo (DOI: 10.5281/zenodo.20128095). Four scripts are included: uintatheres.R provides classical statistical tests and multivariate analyses of dimorphism in Uintatherium anceps, bison.R provides classical statistical tests and multivariate analyses of dimorphism in Bison bison, correlationAndSensitivityTests provides tests of correlation between mean values and the difference between the values obtained by measuring by-hand and using ImageJ for each metric, and simulationTest.R provides a simulation to quantify sources of error when using ImageJ to measure specimens.
