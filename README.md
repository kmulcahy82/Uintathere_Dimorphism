# Uintathere_Dimorphism
Code used in the project "Linear morphometrics fail to support strong sexual dimorphism in Uintatherium anceps." These analyses test the classical paleontological hypothesis that uintatheres, mammals belonging to the extinct order, Dinocerata, exhibit strong sexual dimorphism. 

All scripts are run in R. Datafiles used can be found on Zenodo (DOI: 10.5281/zenodo.20128095). Six scripts are included: uintatheresMain.R provides classical statistical tests and multivariate analyses of dimorphism in Uintatherium anceps, uintathereGrowthCurve.R includes effect size analyses in Uintatherium anceps, bisonMain.R provides classical statistical tests and multivariate analyses of dimorphism in Bison bison, bisonGrowthCurve.R includes effect size analyses in Bison bison, cvAnalyses.R includes variance-based analyses of dimorphism, and correlationTests.R provide tests of correlation between mean values and the difference between the values obtained by measuring by-hand and using ImageJ for each metric to verify that this error does not increase with measurement size.
